# SONAR – 🎵

SONAR es una aplicación web full‑stack inspirada en Spotify, diseñada como showcase profesional.  
El proyecto combina arquitectura moderna en **React + TypeScript**, un diseño minimalista en **dark mode** con acento magenta, y un backend simulado para gestionar librerías musicales.

## ✨ Características principales
- 🎶 **Reproductor integrado** con soporte para audio y video.
- 🔍 **Buscador dinámico** de canciones con acciones rápidas (play, add to queue).
- 📂 **Gestión de tracks**: carga de temas desde JSON y subida manual mediante formulario.
- 💾 **Persistencia opcional**: posibilidad de guardar en `localStorage` o reproducir temporalmente.
- 📑 **Playlist y cola de reproducción** con controles de volumen, shuffle y repeat.
- 🖤 **UI minimalista**: dark mode, magenta como color de marca, accesibilidad cuidada.
- 🛠️ **Arquitectura clara**: context providers, modular CSS y documentación de onboarding.

## 🚀 Objetivo
Este proyecto fue creado como **showcase profesional** para demostrar:
- Buenas prácticas de arquitectura y refactorización.
- Eliminación de legacy code y estructura mantenible.
- Diseño accesible y pulido, listo para portfolio o LinkedIn.
